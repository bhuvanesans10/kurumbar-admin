# Kurumbar Admin Dashboard

React 19 + Vite + TypeScript + Tailwind CSS 4 administration console for managing Kurumbar members, news, matrimony verifications, sales listings, job posts, and audit logs.

## Setup

```bash
cp .env.template .env
pnpm install
pnpm run dev
```

## Scripts

- `pnpm run dev` — Start local Vite dev server
- `pnpm run build` — Run TypeScript check (`tsc -b`) and production bundle
- `pnpm run lint` — Run `oxlint`
